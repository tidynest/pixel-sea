Why stills. A GitHub avatar will not animate. The upload keeps one frame whatever you feed it, so the frame is chosen here with --at rather than by GitHub. The 1 MB avatar limit never binds: the largest of these is 90 KB. Compose for the circle, since that is what the site renders.

The animated set

These are for a profile README (<user>/<user>), a repo README, or an issue comment, where animation does play. 200×200, 32 colours, 8 s at 10 fps, each deliberately under 1 MB. They are not embedded on this page because eleven decoding at once will spin a laptop's fans. See demo/themes.html for these in motion.

Storm is the tightest of the eleven, because heavy cloud and constant whitecaps are the least compressible thing this renderer makes. If it gains detail it is the first file to break the ceiling, and dropping it to 7 s buys back about 115 KB. Gloaming is the far end of the same axis at 435 KB, half of storm, and the gap is noise rather than subject: calm water, almost no whitecaps and a star field a tenth of night's leave far less per pixel that will not compress.
